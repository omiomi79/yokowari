# ヨコ割をください ／ タテ割もください

画像を分割してダウンロードできるWebツールです。2つのページがあり、ヘッダーで行き来できます。

| ページ | URL | 分割 | ハンドル |
|---|---|---|---|
| ヨコ割をください | `/` | 横に3分割・4分割 | 2〜3本（ドラッグで位置調整） |
| タテ割もください | `/tate/` | 上下に2分割 | 1本（ドラッグで位置調整） |

ヨコ割はX（Twitter）に複数枚投稿して、横に繋がった1枚の絵として見せる用途を想定しています。
タテ割は縦長の画像を上下に分け、**下半分を先に投稿 → それを引用リポストして上半分を貼る**ことで、タイムラインで上下に繋がって見せる用途です。

2ページは `app.js` / `i18n.js` / `style.css` を共有し、`<html data-app="yoko|tate">` でどちらかを判定します。
ページ固有の文言は `i18n.js` の `PAGE_OVERRIDES` で上書きしています。

## 特徴

- 画像はドラッグ＆ドロップ / クリック選択 / Ctrl+V 貼り付けで読み込み
- ヨコ割: 3分割・4分割を切り替えてプレビュー ／ タテ割: 上下2分割
- **分割位置をドラッグで調整可能**（← → キーでも1px単位で微調整、均等位置には自動で吸着）
  - 均等でなくなると警告を表示。Xの複数枚投稿は各コマが同じ幅で表示されるため、
    幅を変えると横に繋がって見えなくなる（「均等に戻す」ボタンで復帰）
- 保存形式は JPEG（品質92%・X推奨）と PNG（高画質）
- 割り切れない余りのピクセルは左のピースから1pxずつ配分（合計は元画像と同じ）
- 1枚が5MBを超えた場合は警告表示（Xの上限は1枚5MB）
- **処理はすべてブラウザ内で完結** — 画像はどこにも送信されません
- 日本語・English・한국어の3言語対応（初回はブラウザの言語設定に合わせ、選択内容は次回以降も保持）

## 使い方

1. ページを開いて画像をドロップ
2. 分割数と保存形式を選ぶ
3. 「まとめてダウンロード」
4. Xに投稿するときは 1 → 2 → 3 の順に画像を選択

## 公開方法（GitHub Pages）

ビルド不要の静的サイトなので、リポジトリにpushしてGitHub Pagesを有効にするだけです。

1. このリポジトリをGitHubにpush
2. リポジトリの **Settings → Pages** を開く
3. Source を **Deploy from a branch**、Branch を `main` / `(root)` に設定
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## ローカルで動かす

静的ファイルだけなので、任意のHTTPサーバーで開けます。

```bash
npx serve .
```
